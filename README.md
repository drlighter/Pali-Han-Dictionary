# 📚 四語檢索．巴漢辭典資料庫 (StarDict 格式)

本專案提供基於 StarDict 格式的**「巴漢辭典資料庫」**。歷經深度優化與精準轉換，旨在為南傳聖典、原始佛法之研究者與修行人，提供最流暢、全面的檢索體驗。

## ✨ 專案特色

* **海量辭彙**：收錄豐富核心辭彙。
* **四語全功能檢索**：完美支援 **巴利文 (Pāli)、繁體中文、簡體中文、英文** 同時搜尋檢索。
* **精準繁簡轉換**：特別將原始數據中的簡體中文資料，進行了極高精確度的繁體化轉換，全面符合繁體使用者的閱讀習慣。
* **跨平台相容**：完美支援 Android 端 (GoldenDict) 與 PC 端 (GoldenDict NG)。

## 📲 Android 13+ 新版系統安裝阻擋排除教學

> ⚠️ **安裝痛點**：
> 由於 Android 13 及其後續版本（Android 14、15）強化了安全機制，系統會預設封鎖 Target SDK 版本較舊的應用程式，導致 GoldenDict 2.4.0 APK 可能會無法直接點擊安裝。

### 💡 解決方案：使用 ADB 繞過安全限制安裝

請開啟手機的「開發人員選項」並啟用「USB 偵測」，將手機連線至電腦，使用電腦的 ADB 工具執行以下強制作業指令進行安裝：

```bash
adb install --bypass-low-target-sdk-block GoldenDict2.4.0.apk

## 🛠️ Android 15+ / GoldenDict 2.4.0 閃退與編譯問題排解教學

> ⚠️ **核心痛點**：
> 在 Android 15+ 系統上執行 GoldenDict 2.4.0 時，首次讀取本資料庫（由於體積較大）會引發記憶體溢位而導致**程式崩潰、閃退**。此時系統會卡在編譯階段，並在後台留下一個未完成的 `.tmp` 暫存檔。

### 💡 獨家解決方案：跨版本索引檔「偷天換日」大法

**★ 超級重要：** 
請勿將舊裝置的索引檔原封不動複製過去！即便您手動刪除了失敗的 `.tmp` 檔案，只要「新索引檔名」與 Android 15 系統背後計算的「預期雜湊值（Hash）」不同，GoldenDict 就完全不認它，依然會強制重新編譯並再度崩潰。**必須嚴格依照以下步驟修改檔名！**

#### 📝 具體操作步驟：

1. **獲取成功的索引檔（二選一）**：
   * **方法 A（推薦）**：直接下載本專案隨附已編譯好的通用索引檔（檔名範例：`28dcdec7dc1d0254a2a7f20b81f2f5cf0113`）。
   * **方法 B**：在其他能正常讀取此字典的裝置（如 Android 14 手機/平板、或電腦端）完成首次編譯後取得。

2. **尋找 Android 15+ 裝置上的暫存檔名**：
   * 用傳輸線連接電腦或使用手機檔案管理器，進入 Android 15 裝置的：
     `內建儲存空間/GoldenDict/.config/index/`
   * 找到編譯失敗留下的 `.tmp` 暫存檔（例如：`f411070050635f684961e8b1848b5f2f6892.tmp`）。
   * **完整複製並記下這串英數相間的檔名**。

3. **重新命名成功的索引檔**：
   * 將步驟 1 取得的成功索引檔，重新命名為步驟 2 所記錄的那串特定檔名（**請務必移除 `.tmp` 副檔名**）。
   * *例如：將 `28dcdec7dc1d...` 改成 `f411070050635f684961e8b1848b5f2f6892`*。

4. **覆蓋與替換**：
   * 刪除 Android 15+ 裝置中原本那個失敗的 `.tmp` 暫存檔。
   * 將剛剛重新命名好的成功索引檔，放回 `.config/index/` 資料夾內。

5. **完美開啟**：
   * 重新開啟 Android 15+ 上的 GoldenDict 2.4.0。
   * 程式將直接偵測到相容的索引，**完美跳過編譯階段，直接進入查詢頁面**，所有功能均完全正常！
